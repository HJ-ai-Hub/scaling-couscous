# EZ4U Mobile — 营运工具 (Task 1 & 2)

> 本项目原名 SUN SMART，现已更名为 **EZ4U Mobile**。下方引用的 Master Document 仍沿用原文件名。

基于 `Project A OS · SUN SMART 经营操作系统 Master Document V0.7`（第1-3、5、6、8章及 Decision Log）建立的两个可直接使用的工具，用于补上文件中第6章「财务预算」和部分营运记录系统的缺口。

## 1. `app/index.html` — 每日营运系统

单一 HTML 文件，双击即可在浏览器打开使用，**完全离线运行，无需安装、无需网络、无需登录**。数据保存在本机浏览器（localStorage）。

覆盖任务一的全部 6 项功能：

| 功能 | 对应文件章节 |
|---|---|
| 每日现金结算（简单总额法：期初备用金 + 现金销售 − 现金支出 = 应有现金，比对实际点算） | 3.10 支付系统 Checklist |
| 每日结算程序（全渠道销售汇总 + 非现金渠道到账确认 checklist） | 3.10 / 3.16 阶段一 Checklist |
| 采购记录系统（新机/二手机/配件，含IMEI/SKU、供应商、付款条件） | 3.6 / 3.7 / 第8章供应商数据库 |
| 销售记录系统（自动带出在库成本、自动计算毛利） | 2.1-2.10 商业模式 |
| 库存记录系统（采购−销售自动计算在库数量与加权平均成本，低库存/缺货预警） | 第4章 库存管理方案（Decision Log #007：Google Sheets 路线的离线版替代） |
| 费用记录系统（租金/工资/广告等分类） | 2.16 核心成本结构 |

首页看板会显示今日销售额、现金销售、毛利、费用、结算状态与库存预警。所有记录均可导出为 CSV，完整数据可一键导出/导入 JSON 备份 —— **建议每天结算后导出一次备份**，因为数据只存在打开这个文件的浏览器里。

打开方式：直接用浏览器打开 `app/index.html`（Chrome/Edge/Safari 均可），可以把这个文件放在店里电脑桌面，或者做成书签常驻使用。

## 2. `finance/SUN_SMART_CAPEX_OPEX.xlsx` — CAPEX/OPEX 财务模型

对应任务二，补上文件「第6章财务预算（待完成）」的缺口。用 `finance/generate_capex_opex.py` 生成，包含 6 个工作表：

1. **使用说明** — 如何使用这份表
2. **总览** — CAPEX、OPEX、总启动资金需求、是否落在 RM50,000-100,000 预算区间、12个月预测摘要
3. **关键假设** — 所有可编辑假设集中在这一张表（毛利率、收入结构、库存分配、支付手续费费率等），其余表格全部引用这里，改一处全表联动
4. **CAPEX 开店资本支出** — 商场租赁一次性费用、装修、设备、支付与系统开办费、公司与合规开办费（呼应待完成的第9章法律与文件）、首批库存（自动按70/20/10比例计算）、现金流保护储备
5. **OPEX 每月营运支出** — 场地、人员、支付手续费、营销、系统订阅、售后与风险准备、其他行政
6. **12个月现金流预测** — 按销量增长率自动预测12个月营收、毛利、手续费、净利润、累计现金流，标注 Decision Log #024 商业模式验证标准（连续3个月盈利+正现金流）

黄色格子 = 可编辑输入，其余为公式自动计算。拿到商场 Level B 租金报价、供应商 Level B 价格后，直接回来更新「关键假设」和「CAPEX/OPEX」里对应的黄色格子即可，总览会自动重新判断是否仍在预算区间内。

重新生成（例如改了脚本逻辑后）：
```bash
cd sun-smart/finance
pip install openpyxl
python3 generate_capex_opex.py
```
